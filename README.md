## Projeto em destaque

### PneuFlow

**Sistema de gestão para lojas de pneus**

O **PneuFlow** é uma aplicação web criada para ajudar lojas de pneus a terem uma vitrine digital, gerenciar catálogo, acompanhar leads e organizar informações comerciais.

**Principais recursos:**

- Landing page comercial
- Cadastro e login de lojistas
- Dashboard administrativo
- Gestão de pneus
- Gestão de vendedores
- Leads via WhatsApp
- Vitrine pública da loja
- Métricas comerciais
- Política de privacidade e aceite de termos
